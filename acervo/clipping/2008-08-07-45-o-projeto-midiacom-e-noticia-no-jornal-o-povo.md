# O Projeto Midiacom  é notícia no Jornal O Povo

## Resumo publicado no site do Iteva

O projeto Midiacom, desde 2004, seleciona e capacita jovens estudantes de escolas públicas do Ceará para produção de multimídia, computação gráfica e comunicação digital com alto padrão de qualidade, para inseri-los no mercado de trabalho.
