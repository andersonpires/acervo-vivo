# Desenvolvimento de Software

Tecnologia e comunicação

### Desenvolvimento de Software

Desenvolvimento de Software

A área de Desenvolvimento de Software é complexa e transformadora, a começar pelas pessoas que a executam, todos oriundos de escolas públicas. O setor foi pensado com o objetivo de capacitar adolescentes e jovens, com a finalidade de encontrar cada vez mais soluções para mercados desassistidos e, consequentemente gerar oportunidades de progresso e desenvolvimento socioeconômico.

Por meio do conhecimento adquirido em sistema computacional e pelo bom desempenho, conquistaram a sonhada bolsa de estudos para a universidade em Ciência da Computação. E o resultado culminou no desenvolvimento de alguns softwares internos para atender as necessidades administrativas do instituto, assim como trabalhos de demandas externas.

Como forma de expandir o setor, ampliar as oportunidades de trabalho e renda, desenvolvimento humano, além de gerar sustentabilidade para a instituição, com foco em negócios sociais, a proposta em estudo é desenvolver softwares para dois nichos de mercado, atualmente desassistidos.

Um deles, está relacionado às secretarias municipais e estaduais de educação, que necessitam de um software de gerenciamento, que interligue todas as ações da secretaria. O outro nicho é o terceiro setor, que também carece de soluções tecnológicas, como um software para gestão de projetos incentivados que permitirá fazer todo o processo de gestão, entre outras ações.
