# Projeto Conectividade

## Resumo

Vídeo do projeto Conectividade, que ensina idosos a usar o celular. Thaís Lopes, educadora social, de camisa com a marca ITEVA, conta a empolgação de trabalhar no projeto, e participantes falam do que mudou: ligar para a ambulância, falar com o filho, ver vídeos, tirar fotos. Falas sem legenda de nome descrevem o objetivo do projeto e a autonomia alcançada pelos alunos; o vídeo fecha com a cartela de parceiros.
